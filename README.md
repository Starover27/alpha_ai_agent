# 🎙️ Альфа — локальный голосовой AI-ассистент для Windows

![Python](https://img.shields.io/badge/Python-3.10%2B-3776AB?logo=python&logoColor=white)
![Platform](https://img.shields.io/badge/Platform-Windows-0078D6?logo=windows)

> Голосовой ассистент, который **полностью работает локально** и не требует интернета: распознаёт русскую речь, понимает команды с помощью локальной LLM и выполняет их на компьютере — открывает программы и файлы, ищет документы в сетевых папках и составляет письма в Outlook. Все данные остаются на вашем компьютере.

## ✨ Возможности

- 🎧 **Распознавание речи (STT)** — офлайн через Vosk, лёгкая русская модель (~45 МБ)
- 🔊 **Озвучка ответов (TTS)** — через системный движок Windows (pyttsx3)
- 🧠 **LLM-агент** — многошаговый цикл рассуждений (ReAct, до 6 шагов) с вызовом инструментов через JSON
- 📂 **Поиск и открытие файлов** — строит индекс программ и документов (включая сетевые папки), находит и открывает нужное
- 🖥️ **Запуск приложений** — Outlook, Word, Excel, браузер и любые другие программы
- 📧 **Интеграция с Outlook** — поиск контактов и создание черновиков писем (через COM/pywin32)
- 🖱️ **Управление GUI** — клики мышью, ввод текста, нажатия клавиш (pyautogui)
- 🔒 **Приватность** — ни один запрос не уходит наружу: STT, LLM и TTS работают локально

## 🗣️ Примеры голосовых команд

| Скажите… | Альфа сделает |
|---|---|
| «Открой аутлук» | Найдёт Outlook в индексе и запустит его |
| «Найди договор с Ромашкой» | Поиск по индексу документов и открытие файла |
| «Напиши письмо Иванову» | Найдёт контакт в Outlook и создаст черновик письма |
| «Открой отчёт за сентябрь» | Поиск документа в сетевой папке и открытие |

## ⚙️ Как это работает

```
🎤 Микрофон
   │  sounddevice (16 кГц, mono)
   ▼
👂 Vosk — распознавание речи → текст
   ▼
🧠 Agent (brain/agent.py)
   │   запрос к LLM (LM Studio, OpenAI-совместимый API)
   │   LLM возвращает JSON: {"tool": "...", "args": {...}}
   │   агент выполняет инструмент и снова думает (до 6 шагов)
   ▼
🛠️ Инструменты агента
   • search_system_index — поиск по data/system_index.json
   • open_path           — открытие файлов и программ
   • find_contact        — контакты Outlook
   • create_email_draft  — черновик письма в Outlook
   ▼
🔊 Ответ → pyttsx3 (TTS) → голос
```

- **`main.py`** — главный цикл: слушает микрофон → передаёт текст агенту → озвучивает ответ.
- **`brain/agent.py`** — ведёт историю диалога, вызывает LLM, «умным» парсером извлекает JSON-вызов инструмента из любого текста, выполняет цепочку действий.
- **`build_index.py`** — одноразовый сканер системы: обходит реестр установленных программ, сетевые ресурсы (`net share`, `net view`, `net use`, пинг подсети) и собирает список документов → `data/system_index.json`.

## 📁 Структура проекта

Код ассистента лежит в папке `alfa/`:

```
alfa/
├── main.py                 # Точка входа — главный цикл ассистента
├── config.py               # Все настройки: пути, LLM-сервер, аудио
├── build_index.py          # Сканер системы и сети → data/system_index.json
├── check_mic.py            # Список микрофонов (узнать индекс устройства)
├── requirements.txt        # Зависимости
├── audio/
│   ├── listener.py         # STT: Vosk + sounddevice
│   └── tts.py              # TTS: pyttsx3
├── brain/
│   └── agent.py            # LLM-агент с циклом tool-calls
└── models/
    └── vosk/
        └── vosk-model-small-ru-0.22/   # Русская модель Vosk (уже в репозитории)
```

После первого запуска `build_index.py` рядом появится `data/system_index.json` — индекс программ и документов.

> ℹ️ Вспомогательные утилиты из более ранних версий проекта (`setup.py`, `test_llm.py`, `test_connection.py`, `universal_tools.py`) в этот репозиторий не включены.


## 🛠️ Технологии

| Компонент | Технология | Почему |
|---|---|---|
| Язык | Python 3.10+ | Простота, богатая экосистема |
| STT | [Vosk](https://alphacephei.com/vosk) (`vosk-model-small-ru-0.22`) | Офлайн, быстрый на CPU |
| TTS | pyttsx3 | Системный русский голос Windows, без зависимостей |
| LLM | [LM Studio](https://lmstudio.ai) + `qwen2.5-3b-instruct` | Локальный OpenAI-совместимый сервер; подойдёт и Ollama с `qwen2.5:3b` |
| COM-интеграция | pywin32 | Outlook: контакты и письма |
| Автоматизация GUI | pyautogui, psutil | Клик, ввод текста, управление процессами |
| Аудио | sounddevice, numpy | Низкоуровневый захват с микрофона |

## 🚀 Установка

### Требования

- ОС **Windows** (используются `os.startfile`, win32com, команды `net`)
- Python 3.10+
- Микрофон
- LLM работает на CPU — GPU не обязателен

### 1. Зависимости

```powershell
pip install -r requirements.txt
```

### 2. LLM-сервер

1. Установите [LM Studio](https://lmstudio.ai)
2. Скачайте модель **Qwen2.5 3B Instruct** (квантование Q4)
3. Вкладка **Local Server → Start Server** (сервер поднимется на `localhost:1234`)

> Альтернатива — [Ollama](https://ollama.com): `ollama pull qwen2.5:3b`. Не забудьте поправить адрес сервера в `config.py`.

### 3. Модель Vosk

Русская модель **уже включена в репозиторий** — `alfa/models/vosk/vosk-model-small-ru-0.22`.

Если её нужно обновить: скачайте [`vosk-model-small-ru-0.22`](https://alphacephei.com/vosk/models) и распакуйте в:

```
alfa/models/vosk/vosk-model-small-ru-0.22
```

### 4. Индексация системы

```powershell
cd alfa
python build_index.py
```

Скрипт найдёт установленные программы, подключённые сетевые диски и документы, и сохранит индекс в `data/system_index.json` — по нему ассистент ищет файлы и приложения.

### 5. Запуск

```powershell
cd alfa
python check_mic.py   # узнайте индекс вашего микрофона и впишите его в audio/listener.py
python main.py        # запуск ассистента
```

После приветствия просто говорите с ассистентом. Выход — `Ctrl+C`.

## 🔧 Настройка

Основные параметры — в `alfa/config.py`:

| Параметр | Описание |
|---|---|
| `PROJECT_ROOT` | Корень проекта (замените на свой путь) |
| `VOSK_MODEL_PATH` | Путь к модели Vosk |
| `LM_STUDIO_HOST` | Адрес LLM-сервера (по умолчанию `http://localhost:1234`) |
| `LLM_TEMPERATURE` | Температура генерации (0.3) |
| `MAX_TOKENS` | Лимит токенов ответа LLM |
| `INDEX_EXTENSIONS` | Расширения файлов, попадающих в индекс |

Дополнительно:

- Индекс микрофона — константа `MICROPHONE_INDEX` в `audio/listener.py`
- Подсеть для сканирования сети — переменная `local_subnet` в `build_index.py`
- Проверка микрофона: `python check_mic.py`; связь с LLM-сервером можно проверить любым OpenAI-совместимым клиентом на `LM_STUDIO_HOST`


## ⚠️ Ограничения

- Только Windows — завязано на `os.startfile`, win32com и команды `net`
- Индекс не обновляется автоматически — после изменений в файлах перезапустите `build_index.py`
- Вызов инструментов реализован как «сырой» JSON в ответе модели; парсер в `brain/agent.py` дополнительно понимает markdown-блоки и вложенные скобки
- Точность распознавания зависит от микрофона и шума в помещении
